# 視覺設計：星空匿名聊天室

依照 `docs/architecture.md` 第 7 節「畫面清單」設計。所有元素都要出現；這份文件只決定外觀。

## 風格

- 主題：**夜空／宇宙**。像在深夜望著星空，和陌生人低聲聊天。
- 永遠是深色（主題本身就是夜空），不另做淺色模式。
- 手機優先：先設計 375px 寬，再放大到電腦。
- 背景是深藍紫漸層，加上一層用 CSS 畫的細小星點，慢慢閃爍（使用者設定「減少動態」時停止動畫）。

## 配色（CSS 變數）

| 變數 | 色碼 | 用途 |
|---|---|---|
| `--sky-top` | `#0B1026` | 背景漸層上方（深夜藍） |
| `--sky-bottom` | `#2A1650` | 背景漸層下方（星雲紫） |
| `--panel` | `rgba(20, 24, 56, 0.72)` | 卡片、側邊欄、輸入區（半透明毛玻璃） |
| `--line` | `rgba(160, 170, 255, 0.18)` | 邊框、分隔線 |
| `--text` | `#E8EAFF` | 主要文字（星光白） |
| `--muted` | `#9AA3D6` | 次要文字、時間、系統提示 |
| `--accent` | `#FFD36E` | 點綴（星光金）：按鈕、自己標記、焦點框 |
| `--accent-ink` | `#1A1433` | 星光金按鈕上的文字 |
| `--mine` | `#5B4BD6` | 自己的訊息氣泡（星雲紫） |
| `--theirs` | `rgba(255, 255, 255, 0.08)` | 別人的訊息氣泡 |
| `--danger` | `#FF7A90` | 錯誤、斷線提示 |

代號顏色：依代號計算出固定色相（hue），用 `hsl(色相, 80%, 75%)`，在深色底上都看得清楚。

## 字型

- 內文：系統字型（`system-ui, "Noto Sans TC", "PingFang TC", "Microsoft JhengHei"`），中文清楚。
- 標題「星空匿名聊天室」：同字型加粗，字距稍寬，前面一顆 ✦ 星號。
- 時間：等寬數字（`font-variant-numeric: tabular-nums`）。

## 畫面一：輸入代號

```
┌───────────────────────────┐
│        ✦ 星空匿名聊天室        │
│  不用註冊，取個代號就能聊天     │
│ ┌───────────────────────┐ │
│ │ 你的代號（1～12 字）     │ │
│ └───────────────────────┘ │
│   錯誤提示（粉紅色小字）       │
│ [      進入聊天室      ]     │  ← 星光金按鈕
│  本機示範模式（階段一才有）     │
└───────────────────────────┘
```

- 置中的半透明卡片，最寬 400px，四周是星空。
- 按下後按鈕文字變「連線中…」，並鎖住。

## 畫面二：聊天室

電腦（寬 ≥ 768px）：

```
┌ ✦ 星空匿名聊天室 ─────────── 3 人在線 ── [離開] ┐
│ （斷線／本機示範模式 狀態列，需要時才出現）          │
├──────────────────────────────┬──────────────┤
│  訊息只保留最近的 200 則          │ 線上 3 人      │
│  ──── 2026/11/10 ────          │ ● 小明（你）   │
│  小明 加入了聊天室（灰字）        │ ● Amy          │
│ Amy 14:32                       │ ● Bob          │
│ ┌──────────┐                    │              │
│ │ 嗨！      │                    │              │
│ └──────────┘           14:33   │              │
│                    ┌──────────┐ │              │
│                    │ 晚安～    │ │              │
│                    └──────────┘ │              │
├──────────────────────────────┴──────────────┤
│ [ 輸入訊息…                       ] 12/500 [送出] │
└────────────────────────────────────────────┘
```

手機（寬 < 768px）：

- 線上名單收起；標題列中間的「3 人在線 ▾」是按鈕，點了在標題列下方展開名單，再點收起。
- 「離開」按鈕縮成小字按鈕，維持在標題列右側。
- 輸入區固定在底部，送出按鈕在右邊。

### 元素細節

| 元素 | 外觀 |
|---|---|
| 標題列 | 半透明深色、下方細線；人數前面一個發光的小綠點 |
| 狀態列 | 斷線：粉紅底「連線中斷，重新連線中…」；本機示範：淡金色細條「本機示範模式：只有同一個瀏覽器的分頁能互傳」 |
| 訊息氣泡 | 圓角 16px；自己的用星雲紫、靠右，右下角圓角較小；別人的用半透明白、靠左 |
| 代號 | 只在連續訊息的第一則顯示，用代號固定顏色、小字加粗 |
| 時間 | 氣泡旁邊的小字 `--muted` |
| 日期分隔線 | 置中小字，左右各一條細線 |
| 系統提示 | 置中灰色小字，前面加 ✧ |
| 線上名單 | 每人一列：小圓點（代號顏色）＋代號；自己後面標「（你）」用星光金 |
| 輸入框 | 圓角、半透明底；聚焦時邊框變星光金；鎖住時半透明並顯示「重新連線中…」 |
| 字數 | 輸入框右下小字，超過 450 字變金色、超過 500 字變粉紅 |
| 送出按鈕 | 星光金圓角按鈕，空白或超過字數時變暗、不能按 |

## 無障礙

- 文字和背景對比至少 4.5:1。
- 所有按鈕可以用鍵盤操作，有明顯焦點框。
- 訊息列表是 `role="log"` 並設 `aria-live="polite"`，螢幕閱讀器會念出新訊息。
- `prefers-reduced-motion` 時關閉星星閃爍與捲動動畫。
