# 需求說明

## 這是什麼
一個不用登入的匿名聊天室。所有人在同一個聊天室裡。

## 誰會用
任何知道網站連結的人都可以進來用，可以用電腦，也可以用手機來操作。

## 使用的流程
1. 打開網頁
2. 輸入一個代號
3. 進入聊天室，看到其他人的訊息，也可以送出訊息
4. 想離開時按「離開」，代號馬上釋出給別人用
5. 下次打開網頁時，上次的代號已經幫我填好，按確認才進入

## 畫面上要有
- 誰在線上
- 有人進來或離開時要有提示
- 新進來的人可以看到最近的一些訊息
- 網路斷線時要告訴我，連回來後自動補上漏掉的訊息
- 手機也要好用，不能左右捲動

## 不需要的
- 註冊、登入
- 傳圖片、傳檔案
- 管理者、踢人、刪訊息
- 多個聊天室、私訊

## 技術上我知道的
- 網頁放在 GitHub Pages
- 即時傳訊用 Supabase，透過 WebSocket
- 畫面設計用 /design，前端用 /frontend-design 做出來
